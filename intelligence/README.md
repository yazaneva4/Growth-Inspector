# Saudi Market Intelligence — GrowthSpace

## Schedule
Every Monday, every three hours, Asia/Riyadh (UTC+3). ChatGPT automation handles monitoring and notifications; this document is not itself a GitHub Actions scheduler.

## Coverage
Track consequential Saudi executive education, leadership training, workforce development, upskilling, relevant HR regulations, Human Capability Development Program and Vision 2030 announcements, and competitors relevant to GrowthSpace.

## Reporting format
Store dated reports under `intelligence/reports/YYYY-MM-DD.md` and keep the existing `src/app/dashboard/market-updates` dashboard in sync using the application's established data conventions.

Each substantive development must include:
- Headline and original source URL
- Source publisher and publication date (plus verification date)
- What changed, distinguishing announcements from implementation
- Why it matters to GrowthSpace
- Up to three actionable implications across the entire briefing

Prioritize official Saudi government, regulator, and company announcements, supported by credible reporting. Do not fabricate citations or dates. Deduplicate recurring stories and explicitly say when no meaningful verified updates are found. Never represent an update as published unless the relevant GitHub commit succeeded.
